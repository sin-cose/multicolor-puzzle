# 彩砖谜题编辑器

一个无需安装依赖、可在浏览器中直接打开的彩砖谜题关卡编辑与试玩工具，灵感来自《Undertale》的彩砖谜题。

## 使用方法

1. 用现代浏览器打开 `彩砖谜题编辑器.html`。
2. 在“地图文件”区域填写地图名称；可以通过“导入 TXT”读取关卡，也可以用“导出 TXT”保存当前关卡。
3. 设置网格尺寸（列数 3–40，行数 3–12）。修改尺寸会将砖块重置为粉色。
4. 选择砖块颜色并点击格子进行绘制；拖动网格外的 S（起点）和 G（终点）标记调整入口位置。
5. 点击“开始试玩”，用方向键、WASD 或屏幕方向按钮移动。试玩中可以拖动棋盘查看，视野会跟随角色。

## 砖块规则

| 颜色 | 行为 | TXT 字母 |
|---|---|---|
| 粉色 | 可自由通行 | `P` |
| 红色 | 墙，无法通过 | `R` |
| 黄色 | 进入后退回上一格 | `Y` |
| 绿色 | 谜题中按安全砖块处理 | `G` |
| 橙色 | 进入后变为橙子口味 | `O` |
| 紫色 | 进入后变为柠檬口味，并沿当前朝向强制前进一格 | `U` |
| 蓝色 | 若与黄砖相邻，或角色为橙子口味，则按黄砖处理；否则可自由通行 | `B` |

紫砖强制前进方向上的下一格为黄砖时，按“紫加黄”补丁直接退回紫砖前的上一格。绿砖在谜题模式下不触发战斗。

## TXT 地图格式

文件使用 UTF-8 文本，包含地图名称、地图大小、起点位置、终点位置和地图绘制五部分。地图大小写作“列数 x 行数”；起终点写作边缘名称和从 1 开始的位置编号。绘图区每行使用对应的砖块字母，长度必须等于列数，行数必须等于地图高度。

```text
地图名称：默认地图
地图大小：6列 x 5行
起点位置：左侧,3
终点位置：右侧,3
地图绘制：
PPPPPP
PPPPPP
PPPPPP
PPPPPP
PPPPPP
```

支持的边缘名称为 `左侧`、`右侧`、`上侧`、`下侧`，也接受对应英文 `left`、`right`、`top`、`bottom`。导出文件名使用地图名称；文件名中的非法字符会替换为下划线。

## 项目文件

- `彩砖谜题编辑器.html`：编辑器与试玩功能，独立运行，不依赖外部库。
- `默认地图_5行6列.txt`：可用于导入的空白 5 行 6 列示例关卡。
- `彩砖官方.txt`：提供的 39 列 × 4 行官方地图，可直接导入编辑器。
